1 Executive Summary (CIO View) บทสรุปสำหรับผู้บริหาร (มุมมอง CIO)

This solution turns the world's most familiar messaging app, WhatsApp, into a self-service front door to SAP. An employee simply sends a natural-language question (for example, a stock/inventory summary request); within seconds an AI agent interprets it, retrieves the answer from SAP, and replies in the same chat. There is no new app to install, no portal login, and no training required. โซลูชันนี้เปลี่ยนแอปแชตที่คุ้นเคยที่สุดในโลกอย่าง WhatsApp ให้กลายเป็นช่องทางบริการตนเองสู่ระบบ SAP พนักงานเพียงส่งคำถามด้วยภาษาธรรมชาติ (เช่น ขอสรุปสต็อกสินค้า) ภายในไม่กี่วินาที AI จะตีความคำถาม ดึงคำตอบจาก SAP และตอบกลับในแชตเดิม โดยไม่ต้องติดตั้งแอปใหม่ ไม่ต้องล็อกอินพอร์ทัล และไม่ต้องอบรมการใช้งาน

2 Business Value & Use Case คุณค่าทางธุรกิจและกรณีการใช้งาน

The problemปัญหา

  • Frontline and field staff need SAP data (e.g. stock levels) but rarely have SAP GUI access or training.พนักงานหน้างานและภาคสนามต้องการข้อมูลจาก SAP (เช่น ระดับสต็อก) แต่มักไม่มีสิทธิ์เข้าถึง SAP GUI หรือไม่ได้รับการอบรม
  • Routine questions are funnelled to back-office staff, creating delays and cost.คำถามทั่วไปถูกส่งต่อให้ทีมหลังบ้าน ทำให้เกิดความล่าช้าและต้นทุน

The outcomeผลลัพธ์

  • Self-service answers in the chat app people already use, 24/7.ได้คำตอบแบบบริการตนเองในแอปแชตที่ใช้อยู่แล้ว ตลอด 24 ชั่วโมง
  • Natural language in, formatted business answer out — no query syntax to learn.ถามด้วยภาษาธรรมชาติ ได้คำตอบเชิงธุรกิจที่จัดรูปแบบแล้ว ไม่ต้องเรียนรู้ไวยากรณ์การค้นหา
  • A repeatable pattern: swap the agent or channel to serve new use cases quickly.เป็นรูปแบบที่ทำซ้ำได้ เพียงเปลี่ยนเอเจนต์หรือช่องทางก็รองรับกรณีใช้งานใหม่ได้อย่างรวดเร็ว

Inbound requestคำขอขาเข้า Outbound replyการตอบกลับขาออก Immediate ack (TwiML)การตอบรับทันที (TwiML) AI / SAP trafficการรับส่งข้อมูล AI / SAP
Two parallel paths. The Branch shape splits processing: Branch 1 instantly returns an empty TwiML acknowledgement so Twilio's webhook never times out, while Branch 2 does the slow work (AI + SAP) and pushes the real answer back asynchronously through Twilio's REST API. สองเส้นทางคู่ขนาน รูปแบบ Branch แยกการประมวลผลออกเป็นสองทาง: ทางที่ 1 ตอบรับด้วย TwiML ว่างทันทีเพื่อไม่ให้ Webhook ของ Twilio หมดเวลา ขณะที่ ทางที่ 2 ทำงานที่ใช้เวลานาน (AI + SAP) แล้วส่งคำตอบจริงกลับแบบอะซิงโครนัสผ่าน REST API ของ Twilio

#Stepขั้นตอนWhat happensรายละเอียด
1User sends messageผู้ใช้ส่งข้อความA WhatsApp message reaches Twilio, which forwards it as an HTTP POST (form-urlencoded) webhook.ข้อความ WhatsApp ส่งถึง Twilio ซึ่งส่งต่อเป็น Webhook แบบ HTTP POST (form-urlencoded)
2WSS Listener receivesตัวรับ WSSBoomi's Web Services Server listener (sapmaster) accepts the webhook and starts the process.ตัวรับ Web Services Server ของ Boomi (sapmaster) รับ Webhook และเริ่มกระบวนการ

4aBranch 1 — instant ackทางที่ 1 — ตอบรับทันทีReturns an empty TwiML <Response></Response> immediately so Twilio's webhook does not time out.ส่ง TwiML ว่าง <Response></Response> กลับทันทีเพื่อไม่ให้ Webhook หมดเวลา

6 Key Design Decisions การตัดสินใจเชิงออกแบบที่สำคัญ

Async acknowledgementการตอบรับแบบอะซิงโครนัส

Reply immediately, work later. The empty TwiML ack frees Twilio while the AI (which can take up to ~107s) runs in the background. ตอบรับทันที แล้วค่อยทำงาน TwiML ว่างช่วยปลดล็อก Twilio ขณะที่ AI (ซึ่งใช้เวลาได้ถึง ~107 วินาที) ทำงานเบื้องหลัง

Groovy at the edgesGroovy ที่ขอบกระบวนการ

Lightweight scripts adapt Twilio's form encoding and the agent's SSE/markdown into clean, chat-friendly text. สคริปต์ขนาดเล็กแปลงรูปแบบ form ของ Twilio และ SSE/มาร์กดาวน์ของเอเจนต์ให้เป็นข้อความที่เหมาะกับแชต

WhatsApp-safe outputเอาต์พุตที่เหมาะกับ WhatsApp

Tables flattened and length capped at 1,500 characters to render cleanly within messaging limits. จัดตารางให้เรียบและจำกัดความยาวที่ 1,500 อักขระ เพื่อให้แสดงผลสวยงามภายในข้อจำกัดของแชต

7 Security & Compliance ความปลอดภัยและการกำกับดูแล

  • Secrets externalised. Twilio credentials are injected from environment variables (${TWILIO_ACCOUNT_SID}, ${TWILIO_AUTH_TOKEN}); the AI platform key is stored encrypted in the component, never in plain text.แยกความลับออกจากโค้ด ข้อมูลรับรอง Twilio ถูกฉีดจากตัวแปรสภาพแวดล้อม (${TWILIO_ACCOUNT_SID}, ${TWILIO_AUTH_TOKEN}) และคีย์แพลตฟอร์ม AI ถูกเก็บแบบเข้ารหัสในคอมโพเนนต์ ไม่เก็บเป็นข้อความธรรมดา
  • Transport security. All hops are HTTPS — WhatsApp↔Twilio, Twilio↔Boomi, Boomi↔AI Agent Garden. Outbound Twilio uses preemptive BASIC auth.ความปลอดภัยในการรับส่ง ทุกช่วงการเชื่อมต่อใช้ HTTPS — WhatsApp↔Twilio, Twilio↔Boomi, Boomi↔AI Agent Garden โดยขาออก Twilio ใช้ BASIC auth แบบ preemptive
  • Recommended hardening. Validate Twilio's X-Twilio-Signature on the inbound webhook and restrict the listener to Twilio's IP ranges to prevent spoofed requests.ข้อเสนอเพื่อเสริมความปลอดภัย ควรตรวจสอบ X-Twilio-Signature ของ Webhook ขาเข้า และจำกัดตัวรับให้เฉพาะช่วง IP ของ Twilio เพื่อป้องกันคำขอปลอม
Data governance note: message content (and any SAP data in answers) passes through Twilio and the AI agent. Confirm this aligns with data-residency and PII policies before production rollout. หมายเหตุด้านธรรมาภิบาลข้อมูล: เนื้อหาข้อความ (และข้อมูล SAP ในคำตอบ) จะผ่าน Twilio และเอเจนต์ AI ควรยืนยันว่าสอดคล้องกับนโยบายถิ่นที่อยู่ของข้อมูลและข้อมูลส่วนบุคคล (PII) ก่อนนำขึ้นใช้งานจริง

9 Operations & Risk / Roadmap การดำเนินงาน ความเสี่ยง และแผนพัฒนา

Risks to manageความเสี่ยงที่ต้องบริหารจัดการ

  • Production runtime. Currently on a shared Test Atom; move to a sized production atom/cloud before go-live.รันไทม์สำหรับใช้งานจริง ปัจจุบันอยู่บน Test Atom ที่ใช้ร่วมกัน ควรย้ายไปยังอะตอม/คลาวด์ระดับโปรดักชันก่อนเปิดใช้
  • Latency. AI calls up to ~107s; set user expectations and consider a "working on it…" interim message.ความหน่วง การเรียก AI ใช้เวลาได้ถึง ~107 วินาที ควรสื่อสารกับผู้ใช้และพิจารณาส่งข้อความ "กำลังดำเนินการ…" ระหว่างรอ
  • Webhook authenticity. Add Twilio signature validation (see Security).ความถูกต้องของ Webhook ควรเพิ่มการตรวจสอบลายเซ็น Twilio (ดูหัวข้อความปลอดภัย)

Roadmap opportunitiesโอกาสในการต่อยอด

  • Add error handling (Try/Catch) and alerting on agent/Twilio failures.เพิ่มการจัดการข้อผิดพลาด (Try/Catch) และการแจ้งเตือนเมื่อเอเจนต์/Twilio ล้มเหลว
  • Persist conversation logs for audit and analytics.จัดเก็บบันทึกบทสนทนาเพื่อการตรวจสอบและวิเคราะห์
  • Reuse the pattern for more SAP intents and additional channels (Teams, LINE, web chat).นำรูปแบบไปใช้ซ้ำกับคำสั่ง SAP อื่น ๆ และช่องทางเพิ่มเติม (Teams, LINE, เว็บแชต)

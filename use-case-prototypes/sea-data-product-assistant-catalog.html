Why the two published products look different

subsidiary_master is master data — attributes only, never measures, and it exists because two ERPs disagree about the same entity. subsidiary_performance_consolidated is analytical — historical, many rows, and it needs Data Hub because two ERPs disagree about the same entity. open_receivables_by_subsidiary is operational — current-state, entity-scoped, and it needs no Data Hub at all because a single system owns the fact. Both are data products. A warehouse is a delivery mechanism, not a qualifying criterion.

Ownership Illustrative

A data product without a named owner is just a table someone left behind. The split is deliberate: the business decides what is true, engineering decides how it is delivered.

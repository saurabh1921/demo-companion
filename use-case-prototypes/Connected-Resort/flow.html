Data Hub match, merge & survivorship

Repository Connected-Resorts, model guestmaster, sources OPERA_PMS SALESFORCE_CRM OPERATIONS. Records match on passportHash or loyaltyId; each field then takes the value from the system that owns it.

3

Currency normalisation (local to USD)

From the resort_folio_consolidated data product. Opera PMS and Simphony POS lines are converted at the treasury mid-rate, rounded half-up to 2 dp per line, then summed. Lines in a currency that differs from the folio are flagged.

4

Live data product calls

Each button calls the local facade, which proxies to the Boomi Web Services endpoint with credentials held server-side. If Boomi is unreachable it falls back to the mock implementation of the same contract; the response says which served it.

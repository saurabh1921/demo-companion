What is real here

    
When the demo server is running with Boomi credentials, Check in calls the deployed process
      CR_P5_Guest_CheckIn_Orchestration through /ws/simple/createGuestcheckin.
      The Data Hub steps are live: the golden record is resolved by loyalty id and the stay update is upserted with source
      OPERA_PMS. Opera, the door-lock system, Salesforce, Operations, Simphony and guest messaging are
      stub sends: Message steps that build the exact payload, and the point where a real connector would be swapped in.
      The pipeline then replays the step trace Boomi returned. Offline, or opened as a file, the page replays recorded traces of the same process.

Goodest survey data model

Six Boomi DataHub models in repository CenturyPacificRnD, contributed by source CPF_SURVEY. Responses are anonymous: no names, phone numbers, emails or device IDs are stored anywhere in the model. Customer view · R&D agent view

Entities and relationships

Links read 1 to many (1 and *). Keys are natural keys from the survey platform; DataHub also gives every record its own golden-record ID.

Rules built into the model

  • Batch in the QR. batch_code (format GDS-YYYY-MMDD) comes from the packet QR link and is never asked of the customer.
  • Consent. A Response is only written when consent_given is true; the Boomi process rejects anything else.
  • Canonical answers. selected_value stores the English option code whatever language the owner used, so EN and TL responses aggregate together.
  • Comment hygiene. Phone numbers and email addresses are removed from free_text before it is saved. Analytics only ever report comment theme counts.
  • Source flag. Every record carries source_flag: SYNTHETIC for the seed, LIVE for demo submissions.
  • Small-cell suppression. The analytics layer suppresses any cell with fewer than 5 responses.
  • Retention. Survey.data_retention_note records the policy: 24 months, Philippine Data Privacy Act (RA 10173).

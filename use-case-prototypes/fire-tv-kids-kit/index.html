Fire TV Kids Kit

Parent-controlled videos, a learning quiz and TV messages for Amazon Fire TV, run from a Mac on your home Wi-Fi.

Kids VideosPlays only the videos and channels you approve. No recommendations, no autoplay.
Kids QuizMaths and English quiz that pops up over any app every few minutes of watching.
TV MessageShows a message on the TV and can read it aloud.
Parent RemoteAndroid phone app for the dashboard. Finds the Mac on your Wi-Fi by itself.

The Mac dashboard also has a screen-time timer, bedtime, app blocking, a live screenshot and watch history.

Install on your TV

You need a Fire TV, a Mac on the same Wi-Fi, and an Android phone (optional).

  1. Turn on ADB debugging on the Fire TV. Settings → My Fire TV → About → click the device name 7 times to turn on Developer Options. Then Settings → My Fire TV → Developer Options → ADB debugging: ON. Note the TV's IP from Settings → My Fire TV → About → Network.
  2. Install adb on the Mac, then unzip the kit and open Terminal in that folder. 
    brew install android-platform-tools
  3. Install the TV apps. Replace TV_IP, and accept the "Allow USB debugging" prompt on the TV. 
    adb connect TV_IP:5555
adb -s TV_IP:5555 install -r apks/kids-videos.apk
adb -s TV_IP:5555 install -r apks/tv-message.apk
  4. Turn on the quiz guard so Kids Quiz can appear over other apps. 
    adb -s TV_IP:5555 shell settings put secure enabled_accessibility_services com.home.adyatube/com.home.adyatube.KeyService
adb -s TV_IP:5555 shell settings put secure accessibility_enabled 1
  5. Start the dashboard on the Mac. The first run creates src/config.json. Stop it with Ctrl+C, set "device": "TV_IP:5555" in that file, then start it again. 
    cd src
python3 server.py
    It prints two links with your PIN. Open the "On your phone" link on any phone or laptop on the same Wi-Fi.
  6. Phone app (optional). Install parent-remote.apk on an Android phone (allow "install unknown apps" for your browser). Open it: it searches the Wi-Fi for the Mac, then asks for the PIN, which is the part after ?t= in the link.
  7. Add videos. Open /kids on the dashboard and paste YouTube video, playlist or channel links. They show up in Kids Videos on the TV within a few seconds.

Keep the dashboard link private: the PIN in it gives full control of the TV. The Mac must stay on and running server.py for timers, bedtime and history to work.

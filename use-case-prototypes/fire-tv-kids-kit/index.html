Kids TV Kit works on any Android TV

Parent-controlled videos, a learning quiz and TV messages for Amazon Fire TV, Google TV and other Android TVs, run from a Mac on your home Wi-Fi.

Kids VideosPlays only the videos and channels you approve. No recommendations, no autoplay.
Kids QuizMaths and English quiz that pops up over any app every few minutes of watching.
TV MessageShows a message on the TV and can read it aloud.
Parent RemoteAndroid phone app for the dashboard. Finds the Mac on your Wi-Fi by itself.

The Mac dashboard also has a screen-time timer, bedtime, app blocking, a live screenshot and watch history.

Before you start

  • A TV running Android: Amazon Fire TV / Fire Stick, Google TV, Chromecast with Google TV, or any Android TV box.
  • A Mac (Windows or Linux work too if you run the commands yourself) with Python 3. It stays on while the kit is in use.
  • Same Wi-Fi: the TV, the Mac and your phone must all be on the same home network.
  • ADB debugging switched on on the TV (step 1 below).
  • adb on the Mac: brew install android-platform-tools (needs Homebrew).
  • The TV's IP address: Settings → About → Network (Fire TV: Settings → My Fire TV → About → Network).
  • Optional: an Android phone for the Parent Remote app.

Easiest: let Claude Code do it

If you have Claude Code, it can run every step for you. Do the first two yourself, because they need the TV remote.

  1. Turn on ADB debugging on the TV (see step 1 below) and note the TV's IP address.
  2. Download and unzip the full kit. Open Terminal in the unzipped folder and run claude.
  3. Paste this, with your TV's IP: 
    Read README.md and install this kit on my TV at TV_IP.
Install adb if missing, connect to the TV, install the TV apps,
turn on the quiz guard, set the TV in config.json and start
the dashboard. Then give me the dashboard link for my phone.
  4. When the TV shows "Allow USB debugging?", tick "Always allow" and press OK.
  5. Open the link Claude gives you on your phone. Install parent-remote.apk on the phone if you want the app.

Install by hand

  1. Turn on ADB debugging on the TV.
    Fire TV: Settings → My Fire TV → About → click the device name 7 times to turn on Developer Options. Then Settings → My Fire TV → Developer Options → ADB debugging: ON.
    Google TV / Android TV: Settings → System → About → click Android TV OS build 7 times. Then Settings → System → Developer options → USB debugging: ON (and Network debugging if listed). On newer Google TVs with only Wireless debugging, use its "Pair device with pairing code" and run adb pair IP:PORT on the Mac first.
  2. Install adb on the Mac, then unzip the kit and open Terminal in that folder. 
    brew install android-platform-tools
  3. Install the TV apps. Replace TV_IP, and accept the "Allow USB debugging" prompt on the TV. 
    adb connect TV_IP:5555
adb -s TV_IP:5555 install -r apks/kids-videos.apk
adb -s TV_IP:5555 install -r apks/tv-message.apk
  4. Turn on the quiz guard so Kids Quiz can appear over other apps. 
    adb -s TV_IP:5555 shell settings put secure enabled_accessibility_services com.home.adyatube/com.home.adyatube.KeyService
adb -s TV_IP:5555 shell settings put secure accessibility_enabled 1
  5. Start the dashboard on the Mac. The first run creates src/config.json. Stop it with Ctrl+C, set "device": "TV_IP:5555" in that file, then start it again. 
    cd src
python3 server.py
    It prints two links with your PIN. Open the "On your phone" link on any phone or laptop on the same Wi-Fi.
  6. Phone app (optional). Install parent-remote.apk on an Android phone (allow "install unknown apps" for your browser). Open it: it searches the Wi-Fi for the Mac, then asks for the PIN, which is the part after ?t= in the link.
  7. Add videos. Open /kids on the dashboard and paste YouTube video, playlist or channel links. They show up in Kids Videos on the TV within a few seconds.

Kids Videos, Kids Quiz and TV Message work on any Android TV. A few dashboard extras (the remote's Music button opening Kids Videos, and locking some built-in apps) are Fire TV only.

Keep the dashboard link private: the PIN in it gives full control of the TV. The Mac must stay on and running server.py for timers, bedtime and history to work.

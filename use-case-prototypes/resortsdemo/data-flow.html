1

Source records and cleansing

The source records Data Hub linked to this guest's golden record, and the cleansing rules CR_P1_Guest_Profile_Ingest_Cleanse applies on ingest.

Cleansing rules on ingest

  • Trim and title-case names
  • Email format validation
  • Phones normalised to E.164
  • Loyalty IDs normalised (LOY-######)
  • VIP codes decoded to tiers
  • Passport hashed and masked, never leaves Boomi
2

Data Hub match, merge & survivorship

Records match on passport hash or loyalty ID; each field then takes its value from the system that owns it.

3

Currency normalisation (local to USD)

From resort_folio_consolidated: each line converted at the treasury mid-rate, rounded half-up per line, then summed. Lines in a currency different from the folio are flagged.

4

Live data product calls

Each button calls the Supabase edge function, which calls the Boomi web service with credentials held server-side. No fallback data.

Run a call to see the live response.

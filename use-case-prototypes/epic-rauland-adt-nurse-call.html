What this prototype is

  

    A faithful simulation of the integration, not a live client. The two front ends — Epic's ADT sender and
    Rauland's nurse call board — are stand-ins so the middle is easy to follow. The pipeline stages, shape names,
    field mappings, cross reference values, retry counts and backoff intervals all mirror the real Boomi build:
    four delivery attempts with 2s, 4s, 8s waits, then an envelope written to the
    error queue. PV1-15 carries a site-defined precaution code in this interface.

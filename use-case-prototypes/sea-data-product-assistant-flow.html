Read live from the deployed universe. Won is derived by comparing values; rule is the source ranking configured on the model. Note that two different sources win different fields on the same record — there is no single best system, only a best system per attribute.
This table is subsidiary_master

It has its own catalogue entry, its own accountable owner and two stewards split by field — Finance owns currency, tax ID and the finance contact; Operations owns trading status and who runs the entity. The agent queries it natively, with no API in between, which is why questions like “who is the entity owner for Vietnam?” and “can we post an invoice to Thailand?” are answered straight from the governed record.

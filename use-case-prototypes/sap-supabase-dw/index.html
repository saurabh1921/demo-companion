SAP purchase orders, through Boomi, into the warehouse

Every run reads purchase order lines from SAP (EKKO header + EKPO item), maps them in Boomi and loads them into a Supabase data warehouse. The payload at each step is the real document Boomi handled.

Table service SAURABH_PO_CHANGEDATA_CAPTURE

A Boomi for SAP table service on the SAP demo system (client 100). It joins purchase order headers to their items and is exposed to Boomi as one queryable object, so no ABAP or RFC coding is needed.
